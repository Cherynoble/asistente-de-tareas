1. Where the messages come from

The app merges two sources into a single database:

  • iMessage — read straight off the Mac (read-only). Messages do not arrive on their own: you have to bring them in with Import history (or the automatic daily run).
  • WhatsApp — a mirror of WhatsApp Web (read-only, it never sends). While the app is open and connected, new messages are captured automatically. Older ones are brought in with Import history.

In Settings you choose which conversations are included from each source. If you choose none, all of them are included.

2. “Import history” — filling the database

Brings older messages into the app. The number you type means:

  • WhatsApp: how many messages from each included conversation (e.g. 200 → the last 200 of every chat).
  • iMessage: how many messages in total, most recent first.

Importing only stores the messages; it does not propose tasks yet. It is normal for nothing new to appear in the Inbox after importing until you process. Importing again does not duplicate anything: messages already stored are ignored.

3. “Process new messages” — analysing and proposing tasks

Takes the messages that have not been analysed yet and runs them through the AI. That is where the proposed tasks in the Inbox tab come from. It also:

  • “Reads” every image or PDF with vision (to spot quotations, product photos, and so on).
  • Marks a message as analysed only once, so the next run does not spend anything on it again.
  • Works newest to oldest: today's messages are handled on the first pass, even if you have just imported thousands of old ones.
  • Analyses a limited amount per pass. If older history is still pending, the status says so (“N older messages still queued”). Press Process again whenever you like, or let the automatic daily run drain it.

4. “I sent a message and it isn't showing”

It is almost always one of these three things:

  1. iMessage is not captured automatically. First Import history, then Process.
  2. That conversation is not included. Check the chat selection in Settings.
  3. You haven't processed it yet. Storing a message and analysing it are two separate steps. Press Process new messages: because it starts with the most recent, whatever you just sent or received is handled on that same pass.

5. The “Messages” tab

Shows your conversations exactly as the app stored them, looking the way they do in WhatsApp or iMessage. Use it to check at a glance what was really imported from each chat and what is missing.

  • On the left are all the conversations with their message count, how many are still unprocessed, and how many have files. All of them appear, including the ones not included in Settings — those are marked “not imported”.
  • The search box on the left finds both conversations and text inside messages. Clicking a result takes you to that exact message.
  • Inside a conversation you can search text, filter by unprocessed or with files, and jump to a specific date with the calendar.

You can select messages (tick the box; hold Shift to select a range, and click a date to take the whole day, up to 200) and then:

  • Analyse — runs them through the AI again, and any tasks that come out appear in the Inbox. It is safe to repeat: it does not change whether the message counted as analysed. If nothing is proposed, it is almost always because you already have an open task covering it — and it shows you which.
  • Send to Chat — opens a new conversation with the assistant carrying those messages, so you can ask about them or have it create a task.

6. Recommended routine

  • Day to day: leave the app open. WhatsApp captures itself; press Process new messages whenever you want to review new tasks.
  • Big catch-up: Import history with a high number, then Process. Recent things come out straight away; for older history, press Process again now and then (or let the daily run empty it on its own).
  • Reviewing tasks: check the Inbox (proposals), approve them into Tasks, and use a task's view file link to jump to the file that produced it in Files.
